# تنزيل ملفات Tank Flags

- **Tank-Flags-Source.zip**: المشروع القابل للتعديل، ملفات Blender، النماذج والصوت، وتعليمات التشغيل.
- **Tank-Flags-Web.zip**: نسخة المتصفح المجمّعة. فك الضغط واتبع تعليمات التشغيل؛ فتح HTML مباشرة عبر file: غير مدعوم.
- **Tank-Flags.khgame**: حزمة تجريبية للتكامل مع Kids Hug؛ التكامل الأصلي غير مكتمل وغير معتمد بعد.

افتح الملف المطلوب، ثم اضغط **Download raw file** أو أيقونة التنزيل في GitHub.

هذه نسخة أولية قابلة للتشغيل وليست النسخة الإنتاجية النهائية. راجع README.md و docs/verification.md في جذر المستودع للتفاصيل والقيود.
