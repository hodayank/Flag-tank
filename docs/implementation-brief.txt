18. AUTHORITATIVE NETWORKING
==================================================

Room authority runs the authoritative simulation.

Guest sends intent only:

- Movement direction.
- Held fire state.
- New fire-edge sequence.

Guest does not assign:

- Final position.
- Health.
- Damage.
- Score.
- Wall destruction.
- Pickup ownership.
- Flag ownership.

Initial trial rates:

- Simulation: 30 Hz.
- Input updates: up to 20 Hz plus discrete fire intent.
- Snapshots: 10 Hz.
- Remote interpolation: approximately 100 ms.
- Stale input timeout: 250 ms.
- Reconnect grace: 20 seconds.

Use:

- Protocol version.
- Room ID.
- Match ID.
- Tick.
- Monotonic sequence.
- Stable entity IDs.
- Unique event IDs.
- Validated discriminated message types.

Authority tick order:

1. Validate/accept inputs.
2. Rotate/move with collision.
3. Accept legal shots.
4. Sweep projectiles.
5. Apply damage/disable.
6. Resolve flag and pickup collection.
7. Update timers and safe wall rebuild.
8. Check match end.
9. Emit events and snapshots.

Reject:

- Malformed packets.
- Invalid ranges.
- Nonfinite numbers.
- Old match messages.
- Duplicate events.
- Illegal sender identity.
- Impossible firing rates.
- Oversized payloads.
- Unauthorized final-state events.

Authenticate sender from transport metadata, not a claimed player ID in a payload.

Use reliable delivery for discrete critical state and latest/coalesced delivery for replaceable inputs/snapshots where supported.

If only reliable transport exists, coalesce stale updates rather than accumulating a delayed queue.

Gameplay RNG belongs to authority and uses a shared recorded seed.
Cosmetic randomness is separate.

On disconnect/background:

- Coordinate a shared pause.
- Freeze gameplay timers.
- Clear stale input.
- Permit rejoin to the same authenticated slot.
- Load a full authoritative snapshot before resuming.
- After grace expiry, end as interrupted without inventing a winner.
- No host migration required in this version.
